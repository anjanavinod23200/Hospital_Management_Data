EXCEL DATA ANALYSIS PROJECT

TITLE : Hospital Management Data Analysis

DATASET DESCRIPTION :
        
        This Project analyses a Hospital Management Dataset using Microsoft Excel. The purpose of the project is to analyse hospital data, identify important patterns and trends and provide useful insights and recommendations based on the data.
 
BUSINESS QUESTIONS :
1.	 Which department has the highest number of patients ?
2.	 Which treatment generates the highest total treatment cost ?
3.	 Which month has the highest number of hospital appointments ?
4.	 What is the average treatment cost for patients ?
5.	 Which doctor handles the highest number of appointments ?


DASHBOARD :
      
      The dashboard provides a visual summary of the hospital data using KPI cards, Charts, Pivot Tables and Slicers.

KEY FINDINGS :

●	The department with the highest number of patients was identified from the analysis.

●	The distribution of patients varies across different treatment type, Specialization and hospital branch.

●	The monthly analysis shows that some months have higher billing trend.

●	The analysis shows that patient visits varies across different reasons and time period.

●	The slicers allow the dashboard to be filtered and help users compare different categories and time period.



RECOMMENDATIONS :

●	The hospital can allocate more resources to departments with higher patient demand.

●	Staff and facilities can be planned according to patient demand during high-activity months.

●	Monthly trends can be monitored to improve appointment and staff scheduling.

●	Billing patterns can be reviewed to support better financial planning.

●	Admission trends can be monitored to improve hospital resource management.
